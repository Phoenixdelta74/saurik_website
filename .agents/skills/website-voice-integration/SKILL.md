# Website Voice Integration Skill

## 1. Architectural Principles & Non-Negotiable Rules

1. **Zero-Cost Native Voice Engine Rule (`architecture.md` Section 11):**
   - The primary voice engine **MUST ALWAYS** remain the client's browser-native Web Speech API (`window.speechSynthesis`).
   - Standard visitors with modern devices must never trigger server bills.
2. **Dual-Engine Pipeline Separation (Brain vs. Voice):**
   - **Cognitive Layer (LLM):** Text answers are generated by `api/chat.js` using configured LLM providers (OpenRouter / OpenAI / Anthropic / Ollama).
   - **Speech Layer (TTS):** Spoken audio is generated by `window.speechSynthesis` (client-side) or `api/tts.js` (Maya 2 on Modal).
   - An LLM API key must be configured in `.env.local` (`OPENROUTER_API_KEY`, `OPENAI_API_KEY`, etc.) for text answers to be composed before speech synthesis can occur.
3. **Fallback-Only Boundary:**
   - Server-side TTS is invoked **ONLY** when `findVoice(voices, lang)` returns null (e.g., Bengali `bn-IN` on Windows/Android devices lacking native Indic speech packs).
4. **Resilient Cascading Proxy (`api/tts.js`):**
   - If `MAYA_TTS_ENDPOINT` is configured, route to Maya Serverless GPU on Modal.
   - Use a **45-second timeout guard** on the server proxy to allow cold GPU containers to wake up safely.
   - If Maya fails, times out, or is unconfigured, fall back seamlessly to OpenAI `tts-1`.
   - Never expose API keys or internal GPU endpoints to the browser.

## 2. Server Proxy Integration (`api/tts.js`)

```javascript
// 1. Check for custom Maya 2 Native Serverless GPU endpoint
const mayaEndpoint = process.env.MAYA_TTS_ENDPOINT;
const mayaKey = process.env.MAYA_TTS_KEY || 'saurik_maya_secret_2026';

if (mayaEndpoint) {
  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 45000); // 45s timeout to allow GPU cold boot

    const mayaRes = await fetch(mayaEndpoint, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': mayaKey ? `Bearer ${mayaKey}` : '',
      },
      body: JSON.stringify({ input: cleanedText, voice: chosenVoice }),
      signal: controller.signal,
    });
    clearTimeout(timeout);

    if (mayaRes.ok) {
      const buffer = Buffer.from(await mayaRes.arrayBuffer());
      res.setHeader('Content-Type', mayaRes.headers.get('content-type') || 'audio/wav');
      res.setHeader('Content-Length', buffer.length);
      res.setHeader('Cache-Control', 'public, max-age=86400, s-maxage=86400');
      res.setHeader('X-TTS-Engine', 'maya2-native');
      return res.status(200).send(buffer);
    }
  } catch (err) {
    console.warn('Maya Serverless TTS failed or timed out. Falling back to OpenAI:', err.message);
  }
}
```

## 3. Local Vite Dev Server Middleware (`vite.config.js`)
Because Vite is a frontend bundler that does not automatically execute Vercel serverless functions in `api/`, `vite.config.js` embeds `apiDevPlugin(env)`:
- Dispatches `/api/chat` calls directly to `api/chat.js`.
- Dispatches `/api/tts` calls directly to `api/tts.js`.
- Injects loaded `.env.local` into `process.env` during `npm run dev`.

## 4. Verification Protocol
1. **Direct Proxy Test:** Run `node scripts/test_website_tts_proxy.cjs` to confirm the proxy reads `.env.local` and receives 24kHz audio from Modal.
2. **Tri-Lingual Benchmark:** Run `node scripts/test_maya_tts.cjs --url <ENDPOINT>` to verify English, Bengali, and Hindi generation.
3. **Build Verification:** Run `npm.cmd run build` to ensure zero compilation or bundling regressions.
