# Web release test

Run the platform-neutral `web-release-tester` workflow from this package against the current web application. Detect available terminal, browser, screenshot, file, and test tools first. Inspect repository instructions and establish a baseline. Execute only read-only tests unless the user explicitly authorizes fixes. Produce the report from `references/report-format.md`, cover applicable categories in `references/test-matrix.md`, and state evidence and limitations precisely.
